# 03 — Scénarios

Décrire des situations d’usage concrètes basées sur les personas : qui agit, dans quel contexte, avec quel objectif, quelles difficultés et quel résultat attendu.

Les scénarios servent de pont entre les besoins utilisateurs et l’analyse des tâches.
