Elles vérifient notamment deux champs sans RPE, Entrée, recopie, annulation protégée, correction, reprise/recharge et archivage unique. Elles illustrent les interfaces ; elles ne sont pas les captures du test humain.

Le KLM est adapté à la variante sans RPE : A = 6,35 s ; B = 4,45 s ; C = 2,65 s. Il s'agit de résultats calculés, pas de durées relevées sur les personnes. La présentation donne les séquences et les calculs dans ses annexes.
