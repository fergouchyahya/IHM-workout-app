# 05 — Décisions de conception

Consigner ici les décisions qui influencent durablement l’interface, avec leurs alternatives et les éléments à valider. Créer un fichier par décision, par exemple `DR-001-saisie-resultat.md`.

## Propotype 1 — Conception écran par écran

Le [dossier de conception du prototype](<../../prototypes/propotype 1/README.md>) rassemble les choix transverses confirmés. Les README des écrans décrivent les interactions réalisées. Les validations mentionnées sont des décisions de l’équipe ; les alternatives raisonnées ne sont pas des variantes évaluées auprès d’utilisateurs. La [matrice de traçabilité](../07-evaluation/audit-final-grille.md#traçabilité-conception--interface--évaluation--itération) relie décisions, code et évaluations.

## Décisions

- [DR-001 — Revamp ergonomique du prototype](DR-001-revamp-ergonomie.md) : hiérarchie, navigation, lisibilité et adaptation aux écrans.
