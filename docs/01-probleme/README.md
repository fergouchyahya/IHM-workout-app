# 01 — Problème

Définir le problème à traiter avant de proposer une solution.

À documenter :

- le contexte d’usage et les enjeux ;
- le problème observé ou supposé ;
- les objectifs utilisateurs et les objectifs du projet ;
- les contraintes, hypothèses et critères de réussite.

Conserver ici le cadrage validé par l’équipe et les liens vers les éléments de recherche qui le soutiennent.
